# Card

## A template for simple card!

**Features:-**
- A **simple** card Template
- Fully **Responsive** Design
- **Clean** and **Modern** UI

**How to USE?**
- Give your *div* `class="card"`
- For *card title* use `h2`
- For *card body* use `p`

**Simple Example:**
```
<div class="card">
  <h2> --cardTitleHere-- <h2>
  <p> Replace this with your card Body! </p>
</div>
```
